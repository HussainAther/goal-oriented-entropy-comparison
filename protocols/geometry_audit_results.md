# Independent information geometry consistency audit

## Scope

The audit independently checks the internal numerical
consistency of the archived retrospective information
geometry assessment.

The implementation is provided in
audit_geometry_results.py, with regression tests in
tests/test_geometry_audit.py.

The audit does not import the original geometry
assessment implementation or integrate the model ODE.

## Archived inputs

- target_confirmation_cases.csv
- geometry_validation_pointwise.csv
- geometry_validation_cases.csv
- geometry_validation_summary.csv

The audit is read-only and does not regenerate or
overwrite archived experimental evidence.

## Verification methods

The audit independently verifies:

- Configuration identifiers and positive-time grids.
- Finite numerical records and absence of duplicate keys.
- Divergence and trajectory warning labels.
- Algebraic diagnostic identities.
- Local sufficient conditions.
- Combined normalized analytical bounds.
- Pointwise approximation discrepancies.
- Inequality comparisons and numerical tolerances.
- Configuration-level aggregation.
- Temporal agreement inequalities.
- Four diagnostic features reconstructed from pointwise
  archived quantities.
- Recorded reconstruction discrepancies and tolerances.
- Descriptive quantiles and summary statistics.
- Pearson and Spearman correlations.
- Warning-class descriptive summaries.

General numerical comparisons use absolute tolerance
1e-12 and relative tolerance 1e-9.

Diagnostic reconstruction comparisons use absolute
tolerance 1e-10 and relative tolerance 1e-7.

Inequality violations are defined using the tolerance

    error > bound + 1e-10 + 1e-8 * abs(bound)

consistent with the geometry assessment protocol.

## Corruption-detection tests

Twelve tests deliberately modify individual numerical
or logical quantities in temporary evidence copies.

Two additional tests introduce duplicate pointwise
records and duplicate summary keys.

All fourteen corrupted evidence cases were rejected.

The remaining tests verify successful execution against
the original evidence and the numerical tolerance rule.

The original archived evidence was preserved.

## Reproduction commands

    python verify_archive.py
    python audit_geometry_results.py
    python audit_numerical_results.py
    python -m pytest tests/test_geometry_audit.py -v
    python -m pytest tests/ -q
    python verify_archive.py

The central numerical audit invokes the geometry audit,
allowing existing continuous integration workflows to
check all three experimental analyses.

## Limitations

The audit establishes internal numerical consistency
of archived geometric quantities and descriptive
statistics.

It does not independently reconstruct the model ODE
trajectories or the component-level construction of
the elementary Taylor remainder bounds.

Recorded reconstruction discrepancies are checked
against the protocol tolerances, but are not independently
regenerated by this audit.

The corruption-detection tests establish rejection of
the specific tested inconsistencies, not detection of
every possible coordinated alteration.

The audit does not establish causal explanations of
diagnostic performance, external model validity or
generalization beyond the examined ensemble.

Cross-platform experimental regeneration remains
distinct from archived numerical consistency checking.
