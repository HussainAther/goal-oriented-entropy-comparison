# Isolated ecological numerical reproduction

## Objective

Separate archived evidence integrity from numerical
regeneration of the ecological benchmark.

## Implementation

The ecological computational stages execute in a
temporary workspace containing copies of the
required scientific sources and data.

Archived evidence is verified before and after
execution using SHA-256 manifests.

Regenerated warning predictions are aligned by
ecological group, vessel, posterior draw, and
diagnostic method.

Warning labels must agree exactly.

Prediction probabilities are compared using
absolute tolerance 1e-7 and relative tolerance 1e-6.

These tolerances are numerical engineering choices,
not statistical significance thresholds.

## Initial local verification

- All four ecological computational stages completed.
- Existing scientific verification checks passed.
- Prediction rows compared: 1008.
- Maximum absolute probability discrepancy:
  1.4349958998849388e-09.
- Archived files verified before execution: 9.
- Archived files verified after execution: 9.
- Existing regression tests passed: 57.

The original archived evidence remained unchanged.

## Interpretation

The observed numerical differences are consistent
with small floating-point discrepancies.

Numerical agreement does not require byte-identical
regeneration of floating-point CSV files.

Exact checksums protect the original archived
experimental record.

## Limitations

This initial verification was performed in the
local macOS computational environment.

Cross-platform numerical reproducibility remains
to be evaluated through continuous integration.

The isolated ecological regeneration does not
itself rerun the prospective synthetic confirmation
or the ecological crossed-bootstrap analysis.
